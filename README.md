# Muneeb Gulistan — Portfolio

A responsive personal portfolio built with Next.js 14, React and custom CSS.

## Included
- Dark navy + electric blue visual identity
- Responsive navigation for mobile and desktop
- About, projects, skills, social profiles, journey, experience and contact sections
- Custom CSS project artwork (no stock image dependency)
- SEO metadata and accessible navigation labels

## Run locally

Requirements: Node.js 18.17+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build for production

```bash
npm run build
npm start
```

## Deploy to Vercel
1. Create a new GitHub repository and upload these files.
2. Import the repository into Vercel.
3. Keep the framework preset as Next.js.
4. Deploy.
